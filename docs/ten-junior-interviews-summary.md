## 2. 总结出的初级面试风格

### 2.1 问题短，单轮只问一个主要问题

80 个问题平均长度约 **39.8 字**，最长 110 字。没有出现一轮多个问号的拼盘式问题。

典型问法：

- 先做个简单的自我介绍，重点说你本人亲手做了什么。
- 这个项目里哪一部分明确不是你做的？
- 请从用户入口开始，说明请求经过哪些模块，你负责哪一段。
- 如果参数为空、重复提交或超时，你的代码会怎么处理？
- 这个功能最容易出错的输入或场景是什么？
- 你怎么证明功能真的可用？测了哪些正常、边界和异常用例？
- 你有什么问题想反问面试官？

### 2.2 更接近真实初级面试的“八层推进”

这 10 场实际形成了稳定结构：

1. 个人背景/自我介绍；
2. 个人责任边界；
3. 业务链路；
4. 技术实现和基础边界；
5. 真实故障或异常；
6. 方案取舍；
7. 结果验证；
8. 候选人反问。

这与之前四份真实初级对话中的“自我介绍 → 项目 → 基础题 → Bug → 反问”节奏基本一致，但当前固定轮次更长，适合完整模拟。

### 2.3 不会默认问大架构

80 个问题中没有出现“高并发架构”“异地多活”“组织级技术治理”等默认高级题。

初级问题更关注：

- 你做了什么；
- 你的模块边界；
- 输入、输出和异常；
- 怎么测试和验证；
- 哪部分不是你做的；
- 真实 Bug 怎么定位。

### 2.4 不同岗位的第一问已经能体现差异

例如：

- Java：重点问 Java 实习经历和 CareerNav 后端模块。
- 前端：明确指出简历是 Java 后端方向，追问前端部分实际写了哪些。
- 测试：重点问测试工程师相关经历和具体职责。
- Python：重点问 Python 后端、SQL 和数据处理。
- 运维：直接问为什么从 Java 后端转运维，是否接受运维方向。
- 嵌入式/安全/Go/大模型：首问会指出方向差异，要求候选人说明可迁移经验和边界。

## 3. 本次测试发现的主要问题

### 3.1 第二到第八问的岗位差异化还不够

10 场第一问有 10 种不同问法，但第二到第八问大量复用了同一个阶段模板：

- 第2问：责任边界相同；
- 第3问：业务链路相同；
- 第4问：空值/重复/超时相同；
- 第5问：真实故障相同；
- 第6问：方案取舍出现“你的一个技术选择”这种占位式表达；
- 第7问：结果验证基本相同。

这说明当前初级 Agent 已经做到“短、具体、不架构化”，但还没有完全做到“不同岗位方向有完全不同的追问链”。

### 3.2 方案取舍题需要改成自然问法

在证据卡没有填写具体决策时，第6问会退化成：

> 请说明为什么选择“你的一个技术选择”而不是“另一个备选方案”……

这不符合真实面试官表达。下一轮应改成：

> 你在项目里做过一个什么技术选择？当时为什么选它，有没有考虑别的做法？

### 3.3 得分集中在 58–65

本次毛世豪的回答主要体现：

- 项目个人贡献清楚；
- 能说明 CareerNav 的业务链路；
- 能说出空值、重复提交、检索超时；
- 能说明测试和验证；
- 对非 Java 岗位能诚实说明方向差异。

但得分不高，原因是：

- 部分回答偏概括；
- 非目标方向缺少直接项目证据；
- 量化结果和生产数据不足；
- 回答语气比较稳，但缺少更具体的输入输出和实际代码细节。

这符合“初级可培养、方向有差距、证据还不够强”的现实结果。

## 3.4 评分宽松调整

测试后已将初级评分调整得更适合刚毕业学生：

- 初级基础分从 38 提高到 44；
- 没有生产经验不再重罚；
- “为空、返回错误、测了、跑过、用例”等学生常见表达会被识别为边界或验证证据；
- 初级最终分取“LLM 分”和“初级确定性评分”中的较高值；
- 明确分数带：65–74 为有培养潜力，75–84 为符合初级基本要求。

旧 10 场保留原始分数，不做删除；按新规则重算其原始回答，预计平均分从 **62.3** 上升到 **75.6**。会话 108 首次验证为 **69** 分；进一步增加“有项目事实的相关回答至少进入 65 分档”后，会话 109 验证为 **74** 分。

## 4. 结论

当前初级面试整体风格可以概括为：

> **短问题、基础优先、项目锚定、允许不会、追问边界、要求验证、不默认上架构。**

它已经明显区别于中级/高级面试，但还需要继续补“按岗位方向变化的追问链”，尤其是 Java、前端、测试、运维、数据、嵌入式和安全的第4–7问。
