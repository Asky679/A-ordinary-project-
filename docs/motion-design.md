# 启程动效规范

动效从短时反馈到页面叙事逐级组织。浏览器对减少动态效果的系统设置具有优先权，页头也有可记忆的动效开关。静态状态保留全部入口、当前选择、处理状态和结果。

| 层级与触发 | 对象与运动 | 时间与缓动 | 完成与反馈 | 成本与静态替代 |
| --- | --- | --- | --- | --- |
| L1 按下操作，键盘聚焦 | 原生焦点描边、按钮的按压和实底变化 | 按钮状态 180 ms，描边即时 | 可见焦点保留。提交期间显示 busy，防止重复提交 | 颜色与 transform，静态时仍有焦点、busy 和禁用状态 |
| L1 指向建筑、门牌或目录 | 局部暖光照亮建筑，门牌和底栏同步提亮，Canvas 把相连路线改为实线 | 暖光 350 ms，门牌 250–320 ms，路线下一帧更新 | 光标或焦点移开时还原 | 单个已运行 Canvas，静态时即时提亮并重绘实线 |
| L2 选中岗位星球 | 复用参考首页的定位圈与折线路径，邻近位置展开岗位预览 | 星体 480 ms，定位圈 300 ms，折线 800 ms，预览 580 ms | Escape 关闭并把焦点送回星球，键盘确认时可进入岗位详情 | 动画只改 transform、遮罩和路径偏移。减少动效时直接显示 |
| L2 保存简历 | 纸面出现一次短暂描边反馈，保存结果同时进入状态提示 | 630 ms，ease-out | 服务器成功后显示确认，文本预览保留 | 一次纸张局部绘制。静态时只显示状态提示 |
| L3 城市待机 | 水面纹理偏移，远岸光雾浮动，航点沿路线移动 | 水光 9 s，薄雾 16 s，航点约 16 s，平缓循环 | 不遮挡地标与任务目录 | CSS 合成与单个 Canvas。页面隐藏时停止循环，静态保留地图和路线 |
| L4 进入岗位星图 | 地图星标接到星图标题，背景先出现，岗位星层随后显出 | 560 ms | 岗位读取状态由实际请求决定，导航始终可用 | transform、opacity；减少动态时直接显示 |
| L3 天文馆待机 | 微小星尘斜向漂移，行星缓慢调节亮度，点选时提亮并放大 | 星球亮度 6 s 往返，星尘匀速 | 画面持续可点选 | 单个 Canvas，DPR 上限 2。减少动效时绘制固定星尘 |
| L3 室内与温室 | 简历窗光横移、咖啡馆窗光变化、温室光束缓慢转动 | 11–13 s，ease-in-out | 光源留在合理位置，文字始终清晰 | CSS transform 与 opacity；静态时使用场景原始光线 |
| L4 港湾与地点往返 | 地标图记移动到场景标题；返回时逆向落回原地标 | 进入 560 ms，返回 420 ms，使用共享缓动 | 返回恢复地标焦点，支持浏览器前进和后退 | 原生 View Transition；不支持或减少动态时直接切换 |
| L4 打开岗位详情 | 使用 `planet-bridge` 共享所选星球贴图，移动到详情页头部 | 500 ms，共享缓动 | 返回星图时恢复对应岗位选中状态，详情支持直达 | 一个额外的 View Transition 图层。减少动效时直接换页 |
| L2 收录技能卡 | 卡面外框收拢，按钮与图鉴进度同步 | 520 ms，ease-out | 浏览器保存结果，状态区确认收录 | 局部轮廓动画。减少动效时直接更新状态 |
| L1/L4 选中咖啡馆座位 | 焦点点亮圆桌或里间入口。点击后从对应光点推进，工作页显示该练习的室内取景 | 局部光 400 ms，门牌 250 ms，转场沿用 380/500 ms | 场景位置与难度一致，进入后可继续设置 | 局部透明度与一次 View Transition。静态时即时显示选中态和工作页 |
| L5 打开工作室 | 纸页绕左侧装订线轻微展开，接住工作室的地图图记 | 560 ms，共享缓动 | 落到可阅读位置，编辑入口保持可用 | transform 与 opacity；静态版直接显示完整双页 |
| L5 开始练习、收到回复 | 收起准备区，明确显示当前问题，最近反馈紧跟在作答区后，旧问答可展开 | 内容即时替换，保留旧问答阅读的 400 ms 过渡 | 键盘焦点移到回答输入，结束后显示复盘入口 | 原生折叠区与有限的对话行重绘，静态版即时显示内容和焦点 |
| L5 查看成长记录 | 首条具体行动先出现，之后是其余建议 | 每条 540 ms，依次间隔 65 ms，间隔上限 325 ms | 全文一直可访问，评分依据可展开 | 小范围 transform 和 opacity。静态版同时展示全部 |
| L5 项目解析 | 图版扫过一次，真正提交后独立扫描条只在读取期间出现 | 封面 1.35 s，处理中 1.8 s 循环 | 成功后替换为题单和源码证据，失败时终止扫描并显示原因 | CSS transform，静态时用读取状态文字与 aria-busy |

共享缓动为 `cubic-bezier(.2,.72,.22,1)`。场景入口始终可操作。Canvas 绑定路由 AbortSignal 释放 ResizeObserver、MutationObserver 和帧循环。

## 桌面交互补充

| 触发 | 画面反馈 | 时长与成本 | 减少动效 |
| --- | --- | --- | --- |
| 星图首批岗位可用 | 取景框与星标标签对齐，加载遮罩退出 | 对齐 460 ms。遮罩只反映实际等待，导航仍可用 | 直接显示可用状态 |
| 拖动、滚轮、点星 | 拖动跟随指针，松手后减速，缩放以指针为锚。点星对焦，关闭恢复原视野 | 摄像机只在过渡期间请求动画帧。星图与背景使用分层 CSS transform，预览位置随视野更新 | 保留控制，取消惯性与插值 |
| 简历建议返回或切换 | 批注以短遮罩呈现，逐条采纳或撤回，并定位到预览的项目段落 | 250 ms，ease-out。动画局限于批注文字区域 | 直接显示批注 |
| 选择咖啡馆座位 | 现有场景转场跟随座位位置，落到对应桌面图 | 桌面图 480 ms，使用既有场景缓动。会话恢复直接呈现文字练习 | 直接进入练习 |
| 拖动成长记录时间尺 | 展开选定档案，可分别挑选两场练习的回答 | 180 ms，ease-out。翻阅只使用已读取的数据 | 立即切换档案 |
| 上传 ZIP 或分析仓库 | 等待时显示读取状态，返回后呈现证据目录。选择调用可高亮代码片段 | 等待提示以 1.35 s 周期变换边线，无虚拟进度。目录和片段由真实响应生成 | 静态提示，结果照常可用 |

### 天文馆镜头（桌面）
- 参考 Cosmic Broth 公开前端的视口宽度、设备像素比归一化与星球 0.8 倍背景位移；本项目的拖动基准较参考低 22%。持续拖动平滑追随目标，松手后只收敛到最后位置，没有额外惯性。系统减少动态或关闭动效时直接更新。
- 滚轮调焦维持 0.94–1.55 倍。点选星球只显示详情，不推镜头；星球下方没有常驻标签。


### 场景自动动效（桌面）
- 港湾岸边灯光的倒影随细浪断开和重合。
- 咖啡馆两只杯子的蒸汽以不同节奏卷曲。
- 项目观察室的原有扫光每 2.8 秒从左到右扫过，铜线随扫光短暂亮起。
- 天文馆用三层、共 1140 个大小不一的白点表现远近。三层跟随镜头平移和调焦，较大的前景白点移得更远。两颗小型伴星补充远近层次。
- 画布随场景关闭释放，后台暂停绘制，站内关闭动效或系统减少动态时显示静态原画。



- 场景直接显示原画。观察室在蓝图就绪后启动原有扫光，天文馆在岗位请求期间显示状态提示。


- 港湾往返使用统一的共享图记串联地图和场景。纸页轻开、咖啡馆短距离横移、花园静态叠化、蓝图向上就位后继续原有扫光、星图轻微拉近。先建立场景，再显出座位和岗位星层。转场不添加加载页。
